Try it

A frame takes a few seconds; a clip adds tracking, speeds, possession and space control at about a second per frame on a laptop CPU. Wide, high broadcast angles calibrate best. For anything else, calibrate by hand.

The demo needs the BallHawk server, which is not reachable from this page.

Everything on this site is static except this page. Run the server from the repository, then open this page from it:

uv run --python 3.12 --with-requirements demo/requirements.txt python demo/app.py # then open http://127.0.0.1:7860/demo.html
