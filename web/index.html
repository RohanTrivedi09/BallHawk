BallHawk.

On a wide broadcast shot the football is 3.7 px across when YOLO sees it, smaller than one cell of its finest grid. This project measures how much that hurts, tests five fixes one at a time, and carries the winner into tracking, pitch calibration and an offside visualiser.

How the tactical view works
The pipeline

Five phases, one question each

PHASE 0

Data

372 frames re-split by match, so no clip leaks from train into test.

 PHASE 1

Detection

Resolution, augmentation, a P2 head, class weights and SAHI, one variable at a time.

 PHASE 2

Tracking

ByteTrack IDs and shirt-colour teams. The better detector doubles ball coverage.

 PHASES 3–4

Calibration

Hand-clicked and learned pitch landmarks map every frame onto a 105 × 68 m pitch.

 PHASE 5

Tactical view

Positions, speeds, possession and a per-frame offside line on video.
